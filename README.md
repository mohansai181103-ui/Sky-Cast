SkyCast — City-Based Live Weather Forecast App
1.	Project Overview
A responsive, modern weather web application that displays real-time weather data, 5-day forecast, and air quality index (AQI) using the OpenWeather API.
The app allows users to search for any city worldwide and view temperature, humidity, pressure, visibility, sunrise/sunset times, and more — all presented in a clean and interactive UI.
2.	Features
•	Search weather by city name
•	Real-time temperature, humidity, pressure, and visibility
•	Feels like temperature and weather description
•	Sunrise & Sunset timings based on location
•	5-Day forecast with date & average temperature
•	Hourly temperature forecast (6 upcoming time slots)
•	Air Quality Index (AQI) with CO, SO₂, NO₂, and O₃ values
•	Built with OpenWeather API and Fetch API
•	Clean, minimal UI with responsive design
3.	Technologies Used
•	HTML5, CSS3, JavaScript (ES6+)
•	OpenWeather REST API, Fetch API
•	Asynchronous JS, JSON parsing, Dynamic DOM updates
•	Responsive design, Error handling, Proxy-based CORS bypass
